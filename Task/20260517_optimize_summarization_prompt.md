# 优化文本总结提示词

## 任务概述
优化 `summarize_text.py` 中的默认提示词，使其能够更详细地记录对话的逻辑脉络，适合播客转写文本的总结需求。

## 改动内容
### 修改文件
- `summarize_text.py:35-63` - 更新默认提示词

### 优化要点
1. **结构更清晰**：分为【对话概述】、【对话逻辑脉络】、【关键信息摘录】、【逻辑关系图】四个部分
2. **强调时间顺序**：严格按照对话的时间演进记录
3. **记录逻辑贡献**：每个文本片段的逻辑作用都被记录
4. **突出观点关联**：描述话题之间的递进、并列、转折等关系
5. **支持说话人识别**：如果文本中有明确说话人，会注明发言者

### 新提示词结构
```
【对话概述】
- 主题
- 参与人员
- 整体脉络

【对话逻辑脉络】
- 开篇话题
- 主要讨论点（按顺序）
- 话题转折
- 结论/收尾

【关键信息摘录】
- 重要数据/事实
- 核心观点/主张
- 行动建议

【逻辑关系图】
- 话题间的关联关系
```

## 使用场景
特别适合：
- 播客对话总结
- 多人讨论记录
- 访谈内容整理
- 会议纪要生成
